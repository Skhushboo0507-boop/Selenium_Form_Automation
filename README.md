# Selenium Form Automation Testing

## Project Overview
This project automates a web form using Selenium WebDriver with Python. The automation script validates different UI elements such as text fields, radio buttons, checkboxes, dropdowns, and form submission functionality.

## Key Features
✔ Automated form filling

✔ Radio button selection

✔ Checkbox validation

✔ Dropdown handling

✔ Form submission testing

✔ Success message verification using assertions

## Tools & Technologies
- Python
- Selenium WebDriver
- PyCharm
- Chrome Browser

## Test Scenario
1. Open the application.
2. Enter user details.
3. Select radio button and checkbox.
4. Choose value from dropdown.
5. Submit the form.
6. Verify successful submission message.

## Installation
install Selenium:

```bash
pip install selenium
```

## Run the Project

```bash
python form.py
```

## Learning Outcomes
- Selenium WebDriver fundamentals
- Locators (ID, Name, XPath, CSS Selector)
- Dropdown handling with Select class
- Assertions and validations
- End-to-end form automation
